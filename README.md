# Syntexa
## A programming language with a llvm backend

- This is my first programming language written with an llvm backend
- This programming language features the following syntax

### Variable Declaration
```sh
let x = val;
```

### Variable Assignment
```sh
x = val;
```

### If condition
```sh
if(cond) {
  // Statements
}
```

### While Loop and For Loop
```sh
while(cond) {
  // Statements
}

// For Loop
for(expr; expr; expr) {
// Statements
}
```

### Match (Switch case)
```sh
match (expr) {
case expr -> // Statements
...
}
```

### Functions
```sh
fn name() {
  //Statements
}
```

### Importing modules
```sh
import module
```



### Operators

- Unary
  - Minus (- operator)
  - ex: -23
- Binary
  - Plus
  - Subtract
  - Divide
  - Multiply
  - Modulus
  - Or
  - And
  - Xor
  - Equal
  - Not Equal
- Ternary
  - The Ternary Condition Operator (?)
